# Code of Conduct

## Our standard

Be direct and be civil. Disagree with the work, not the person. Assume
good faith from people who took the time to write an issue or a pull
request.

Not acceptable: harassment, personal attacks, discriminatory language or
jokes, or publishing anyone's private information without consent.

## Scope

This applies to the issue tracker, pull requests, and any other project
space, including comments on shared artifacts and code review.

## Enforcement

Report unacceptable behavior by opening an issue marked private, or by
emailing the maintainer listed in `package.json`. Reports are handled
case by case. Maintainers may edit, remove, or reject contributions and
comments that violate this standard, and may block anyone who repeatedly
violates it.

## Attribution

This document is intentionally short. If a situation arises that it does
not cover, the standard above is the standard: be direct, be civil, argue
about the code.
